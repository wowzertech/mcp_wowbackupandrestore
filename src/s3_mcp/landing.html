WOW AISuite

Model Context Protocol server

Connect your agent to your backups.

Query your Xero & QuickBooks backups from Claude — or any MCP client. One OAuth endpoint, no keys, no install.

Endpoint {{ENDPOINT_DISPLAY}}

Pick your client

Run in your terminal — Claude signs you in on the first tool call:

claude mcp add wow-aisuite --transport http {{ENDPOINT}}

In the Claude web or desktop app — no config file:

Settings → Connectors → Add custom connector
Paste:  {{ENDPOINT}}
Add → Connect  (browser sign-in opens)

In the ChatGPT app — turn on Developer mode, then add the connector:

Settings → Connectors → Advanced → Developer mode
Add custom connector → URL:  {{ENDPOINT}}
Connect  (browser sign-in opens)

Custom connectors need a ChatGPT Plus, Pro, Business, or Enterprise plan.

  }
